# Trans

텍스트를 번역하고 번역 결과를 `.txt` 파일로 저장할 수 있는 웹 앱입니다.

## 기능

- 원문 언어 자동 감지 또는 직접 선택
- 한국어, 영어, 일본어, 중국어 등 주요 언어 번역
- 번역 결과 복사
- 번역 결과 TXT 저장
- 최근 번역 기록을 브라우저 로컬 저장소에 보관
- PWA 설치 지원

## 실행

정적 파일만으로 동작합니다. 로컬에서 확인하려면 저장소 폴더에서 아래 명령을 실행하세요.

```powershell
npx serve . -l 4173
```

그 다음 브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## GitHub Actions 배포

`.github/workflows/deploy.yml` 워크플로가 `main` 브랜치에 푸시될 때 GitHub Pages로 자동 배포합니다.

저장소의 `Settings > Pages`에서 `Build and deployment`의 소스를 `GitHub Actions`로 설정하세요. 이후 `main`에 푸시하면 배포 주소는 보통 `https://god199683.github.io/Trans/` 형식입니다.

## 번역 방식

브라우저에서 온라인 번역 엔드포인트를 호출합니다. 기본 번역 요청이 실패하면, 원문 언어를 직접 선택한 경우 대체 번역 엔드포인트로 한 번 더 시도합니다.
